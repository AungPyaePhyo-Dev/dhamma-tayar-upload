Privacy Policy

Effective October 29, 2026

mm short is a private desktop tool used only by the owner of the YouTube channel ဓမ္မတရားတော်များ to upload Dhamma talk videos to that channel. This policy explains what data the tool accesses and what it does with it.

mm short uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is covered by the Google Privacy Policy.

Data the tool accesses

Only after the channel owner signs in with Google and grants permission, mm short accesses the following through the YouTube Data API:

DataPermissionPurpose
Channel ID and channel nameyoutube.readonly Show the owner which channel is connected.
Titles, IDs and status of the owner's uploaded videosyoutube.readonly Avoid uploading the same talk twice; confirm a video finished processing or went public.
New videos, their titles, descriptions, tags, schedule and thumbnailsyoutube.upload Upload the owner's own videos to the owner's own channel.

mm short does not access data of any other YouTube user, viewer, subscriber or commenter, and it cannot delete videos or change channel settings.

How the data is used

The data is used only to publish videos to the owner's channel on schedule and to keep a local record of what has been uploaded. It is not used for advertising, profiling, or any other purpose.

Where the data is stored

  • The Google sign-in token is stored only on the owner's computer, in a file readable only by the owner's account.
  • A local record of uploaded videos (video ID, title, scheduled date, status) and activity logs are stored on the same computer.
  • mm short has no server. No data is sent to the developer or stored anywhere else.

Sharing

Data obtained through YouTube API Services is not sold, rented or shared with anyone. The only other service involved is the Google Gemini API, which receives the talk title and speaker name (and titles of earlier talks as style examples) to draft the video description and thumbnail text. No YouTube account data, sign-in tokens or personal information are sent to it.

Retention and deletion

  • The sign-in token is kept until the owner revokes access. Access can be revoked at any time from the Google security settings page. After revoking, mm short can no longer access the account.
  • Deleting the tool's local files removes every piece of data it has stored.
  • Videos uploaded to YouTube stay on YouTube until the owner removes them there.

Google API Services User Data Policy

mm short's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This website

This website has no cookies, analytics, or tracking. It is hosted on GitHub Pages, which may record visitors' IP addresses for security, as described in the GitHub Privacy Statement.

Children

mm short is not directed to children and does not collect information from them.

Changes
